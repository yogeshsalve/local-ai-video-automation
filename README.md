# Local AI Video Automation

A local, open-source AI video automation platform that converts
scripts into narrated, captioned, and visually enhanced YouTube videos.

## Objective

The goal of this project is to create a completely local AI-powered
video production pipeline.

## Planned Pipeline

Script
↓
AI Scene Planning
↓
Text-to-Speech
↓
Visual Generation
↓
Caption Generation
↓
Video Assembly
↓
YouTube-ready MP4

## Technology Stack

- Python
- Laravel
- FastAPI
- Ollama
- Local LLM
- Whisper
- FFmpeg
- PostgreSQL
- Redis
- Docker
